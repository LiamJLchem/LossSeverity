
# LossSeverity

<!-- badges: start -->
<!-- badges: end -->

The goal of LossSeverity is to predict when losses are going to occur and how 
severe they will be for life, health, and property insuranceholders.

## Installation

You can install the development version of LossSeverity from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("LiamJLchem/LossSeverity")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(LossSeverity)
## basic example code
```
